# Prerequisites

Property creation is available after owner onboarding, KYC, and payment-account prerequisites are complete. If Add Property is unavailable, confirm the owner-upgrade and payment-connection status in the relevant dashboard. A property should be created by the person or company entitled to list it, using accurate information and legitimate supporting documents.

# Draft and wizard behavior

Choose Add Property to start a draft. The wizard collects information in an ordered sequence rather than treating each screen as a separate property. The current flow covers property type; state, city, pincode, and address; an optional map location; bedrooms and bathrooms; land and built-up area; title; description; monthly rent; security deposit; and amenities. Photos and ownership documents are managed with the property record as directed by the interface.

Progress is saved as a draft so the owner can leave and continue later. Do not repeatedly start new drafts when an existing draft should be resumed. If the local browser no longer remembers the last wizard step, the application can use the stored draft state to continue. Review earlier steps before submission because an auto-saved value can still be inaccurate.

# Accurate listing details

Select only a supported property type. Enter an address and location that describe the property consistently. Bedroom and bathroom counts must reflect usable rooms. Land area and built-up area should use the units and validation presented by the form. Rent and deposit must be non-negative valid monetary values and should match the intended lease terms. The title should identify the listing clearly, while the description should explain relevant features without including private identity, bank, or access information.

# Map location

The map pin is optional where the interface marks it optional. Providing it helps prospective tenants judge location, but it does not replace the required address fields. Do not place a deliberately misleading pin. If map loading fails, the owner can complete required address information and return to the optional map step later where supported.

# Photos and amenities

Upload clear property photos intended for public display. Avoid images containing identity documents, payment information, unrelated people, private correspondence, or access credentials. Multiple useful views help tenants understand the property. Removing an image changes the listing media but does not remove private ownership documents.

Select only amenities actually available, such as those presented by the application. Amenities affect comparison and expectations. If an amenity changes after publication, update the listing rather than relying on a message outside EstateSync.

# Ownership documents

Upload the required ownership certificate before submission and add supported evidence where useful, such as the property deed or tax receipt options shown by the form. Ownership documents are private review material and are not tenant-facing photos. Files should be legible, complete, and associated with the property. Do not upload passwords, banking credentials, or unrelated identity files.

# Submission validation

Submit for Approval becomes available only after required wizard fields and required ownership evidence are present. Missing title, description, address, rent, deposit, bedroom or bathroom counts, area values, or ownership coverage can block submission. Revisit each step rather than creating another property draft. Submission moves the item out of editable draft preparation and into a review state.

# Approval and rejection

Pending Approval means the listing is waiting for authorized review. It is not yet a normal public listing. Approved listings become Active and visible when the rest of their activation conditions are satisfied. Rejected listings display or notify the owner of a reason. Correct the stated issue and resubmit the same property where supported; rejection does not mean the owner must create a duplicate listing.

# Property statuses

Draft is incomplete or not submitted. Pending Approval is awaiting review. Active is approved and available to tenants. Leased means an active lease currently occupies the property. Available Soon indicates the current lease is approaching its end under the lifecycle rules. Rejected requires correction. The current status determines whether tenants can find the property and which owner actions are available.

# Editing after creation

Draft properties can be edited before submission. Approved properties can expose supported editing for details, photos, and amenities, but changes must remain accurate and may be subject to lifecycle restrictions. A leased property cannot be treated as immediately available merely by changing descriptive fields. Lease-driven availability is controlled by the lease workflow.

# Multiple listings and duplicates

There is no general one-property limit, but each property must represent a genuine listing and complete its own review. Avoid accidental duplicate drafts for the same property. If unsure whether submission succeeded, check the Owner dashboard and status before trying again.
