# What EstateSync does

EstateSync connects tenants, property owners, and authorized review staff through one rental-management platform. A tenant can create and verify an account, browse available properties, save interesting listings, request site visits, submit rental applications, sign leases, pay bills, and raise complaints. A property owner can complete the same tenant activities while also listing properties, reviewing applications and visits, creating leases, receiving rent, and responding to complaints. Staff accounts review verification requests and items that require platform approval.

# Typical tenant journey

A tenant normally verifies their email after registration and then completes KYC identity verification. Browsing public property listings does not reserve a property. A tenant may save a property, request a site visit, or submit a rental application; these are separate activities and one does not automatically create another. An approved KYC is required before a rental application can proceed. When an owner approves an application, the owner may create a lease. The tenant signs first, the owner signs afterward, and the fully signed lease goes through final review. Once approved, the lease becomes active and its initial bills are generated. Later activity—including rent payments, renewals, vacate notices, and complaints—is managed from the tenant dashboard.

# Typical owner journey

An existing user becomes an owner by first completing KYC and then upgrading from Profile as an individual or company. Becoming an owner adds owner capabilities; it does not remove tenant capabilities. Before creating a property draft, the owner must connect and complete verification of the payment account used to receive funds. Every property has its own draft, supporting documents, approval state, applications, visits, lease, and complaints. A listing is visible to tenants only after the required information is complete and the listing is approved and active.

# Dashboard views

Tenant and owner functions are separated into dashboard views so that the same account can manage both sides of the rental journey. A user who owns property can still browse or rent a different property as a tenant. Staff dashboards contain review work rather than tenant or owner activity. Private documents remain available only in the part of the application where their review is required.

# Status-driven workflows

Most EstateSync workflows are controlled by status. A Pending item is waiting for a decision or the next participant. Approved means the relevant review succeeded, while Rejected normally includes a reason and may allow correction and resubmission. Draft items can usually be continued later. Active items are currently in effect. Cancelled, Withdrawn, Voided, Terminated, Expired, Resolved, and Closed each describe a completed or stopped workflow and are not interchangeable. Users should check the status shown on the relevant dashboard before trying the next action.

# Important boundaries

Saving a property does not reserve it. Requesting a visit does not apply for it. An approved application does not itself create a lease. Signing a lease does not make it active until both signatures and final review are complete. Creating a payment attempt does not mark a bill paid; payment must finish successfully. Marking a complaint Resolved does not necessarily close it, because the tenant can close it after confirming satisfaction.

# When an action is unavailable

An unavailable button usually means a prerequisite is incomplete, the item is in a status that no longer allows the action, or the action belongs in a different dashboard view. Common examples include applying before KYC approval, creating a property before payment-account verification, editing lease terms after a signature, paying an already paid bill, or responding to a visit that is no longer Pending. Refresh the relevant dashboard, confirm the current status, and complete any prerequisite shown there. If the displayed state and available action still conflict, contact support without sharing passwords, payment credentials, or full identity-document numbers.
