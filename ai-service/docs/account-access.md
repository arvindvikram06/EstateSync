# Creating and verifying an account

Create an account from the registration page using your name, email address, and a password that satisfies the displayed requirements. Submitting registration creates the account but does not immediately permit normal sign-in. EstateSync sends a verification message to the registered email address. Open the newest verification message and follow its link to activate the email. Verification links are intended for the account that requested them and should not be forwarded.

If the verification message is delayed, check spam or junk folders and confirm that the address entered during registration is correct. The login page provides a resend option. Requesting another message may make an older link obsolete, so use the newest message. Repeatedly clicking resend is not helpful; allow normal delivery time before requesting again.

# Signing in and session expiry

After email verification, sign in with the registered email and password. A successful sign-in takes the user to the appropriate application area. Staff members use the designated staff sign-in flow, while tenants and owners use the main sign-in flow. If a page is not available to the signed-in account, return to the appropriate dashboard rather than trying to reach it from an old link.

Sessions are maintained while the application is in use but can expire after inactivity, after browser data is cleared, or when authentication credentials are no longer valid. A normal expired session returns the user to sign-in and does not mean the account was disabled. Sign in again and retry the previous navigation. If the session repeatedly ends immediately, use a fresh browser tab and ensure the browser accepts the application’s required storage.

# Disabled accounts

A disabled account is different from an expired session. An inactive account cannot sign in until it is reactivated through the appropriate support or administrative process. The user should contact support for the reason and next steps. Do not create duplicate accounts to bypass an inactive status, because verification and rental records remain associated with the original account.

# Forgotten-password recovery

Use Forgot Password from the login page and enter the registered email address. EstateSync sends a password-reset link when the account is eligible. Open the newest link and choose a new password. Reset links expire, so complete the change promptly. If a link has expired or was already used, request another one. For privacy, the recovery screen may not disclose whether every entered address belongs to an account.

If the message does not arrive, check junk folders, verify spelling, and request a new link after waiting. Never share a reset link, one-time token, or password with support staff or another user. EstateSync support should not need the current password to help with account access.

# Managing the profile

Open Profile from the account menu to review or update supported personal details such as name and phone number. Save changes before leaving. Changing profile information does not automatically change identity-verification documents, signed leases, or historical records. Some identity-linked fields may be locked after verification and require a formal correction process rather than ordinary profile editing.

To change a password while signed in, use Change Password from Profile. Enter the current password and then the new password. If the current password is unknown, sign out and use the forgotten-password flow instead. Changing the password may require authentication again on existing sessions.

# Using tenant and owner features

A new standard account begins with tenant features. Completing an owner upgrade unlocks owner features on the same account; it does not require a second account and does not remove tenant access. The user can move between tenant and owner dashboards using application navigation. Staff access is separate from the normal customer profile and owner-upgrade process.

# Common access problems

If login says the email is unverified, complete email verification or request a new verification message. If the password is rejected, use password recovery rather than repeatedly guessing. If the account is inactive, contact support. If a page is unavailable, return to the dashboard intended for the signed-in account. If a link from an old email has expired, request a new one. Avoid sending screenshots that expose reset links, passwords, identity numbers, or payment details.
