# Eligibility and submission

A tenant needs approved KYC before submitting a rental application. Open an eligible property and choose Apply. Review the property before submission because applying is a formal request to rent it. Submitting creates a Pending application for the owner to review; it does not guarantee acceptance, reserve the property indefinitely, or create a lease.

Applications and site visits are independent. A tenant may request a visit, apply, or do both in the order supported by the current listing. Saving a property is also independent and does not improve application priority.

# Multiple applications

A tenant can apply to more than one different property. Each application has its own owner decision and status. Multiple applications do not create multiple leases automatically. For the same property, only one application can continue into the successful lease path at a time.

# Tenant application statuses

Pending is waiting for the owner. Approved means the owner accepted the application and can proceed toward lease creation. Rejected means the owner did not accept it. Withdrawn means the tenant cancelled before approval. Completed is used when the application’s associated rental journey has run its course according to the lease lifecycle. Application status is not the same as lease status.

# Withdrawing

A tenant can withdraw an application while it has not been approved and the action remains available. Withdrawal is final for that application and stops it from proceeding to lease creation. An already approved application cannot normally be withdrawn through the same tenant action; the tenant should communicate with the owner before a lease is created if plans changed. Do not sign a lease that does not reflect the intended agreement.

# Owner review

The owner sees applications for owned properties in the Owner dashboard. Review the application associated with the correct property and choose Approve or Reject while it is Pending. The applicant is notified. Approval should be made only when the owner intends to create a lease under agreed terms.

The platform permits only one application to hold the successful path for a property at a time. If another application has already been selected or a lease now occupies the property, approving a competing application is blocked or no longer meaningful. Refresh the list before acting on a record opened earlier.

# What happens when a lease is created

Creating a lease from an approved application establishes the selected tenant-property relationship for that lease. Other Pending or Approved applications on that same property are automatically rejected as required by the one-active-lease workflow, and affected applicants are notified. Applications on different properties are not affected.

# Why Apply may be unavailable

Common reasons include KYC not being Approved, the property no longer being Active or eligible, an existing conflicting application, or a stale page after the property’s status changed. Check KYC status, refresh the property, and inspect Applications before retrying. Repeated clicks should not be used to create duplicate submissions.

# Why Create Lease may be unavailable

The application must be Approved, belong to the owner’s property, and remain eligible for lease creation. The tenant must satisfy required verification, and the property cannot already have a conflicting active lease. If the action disappeared, verify the application and property statuses rather than creating another application.

# Privacy

Owners can review the applicant information exposed by the authorized application workflow, but do not receive unrestricted access to private identity documents or unrelated tenant records. The assistant should explain the process without revealing applicant details, rejection information from another person, or private review data.
