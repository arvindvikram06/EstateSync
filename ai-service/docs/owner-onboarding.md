# Before becoming an owner

EstateSync owner access is an upgrade to an existing account. The user must first have an approved KYC. If KYC is Draft, Pending, or Rejected, complete or correct that process before attempting the owner upgrade. A separate account is not required, and creating one can split verification and rental history unnecessarily.

# Individual and company ownership

Open Profile and choose Become an Owner. Select Individual when properties and payouts are associated with the account holder personally. Select Company when acting for a business entity. Company onboarding requests the business details shown by the form, such as company name, organization type, and applicable registration identifiers. Only provide identifiers that genuinely apply to the selected organization type.

Review the owner type carefully before submission. The choice describes whose name is associated with owner activity; it does not change the property-listing, application, lease, or complaint workflow. If important owner information was entered incorrectly and cannot be edited, contact support instead of creating another owner profile.

# Account behavior after upgrade

Completing the upgrade unlocks the Owner dashboard while keeping the existing tenant features. One person can manage owned properties and also rent a different property. Use the tenant dashboard for personal rental activity and the owner dashboard for owned-property activity. Records remain in the dashboard that represents that activity.

# Connecting the payment account

Finishing the profile upgrade alone is not enough to create a property draft. The owner must complete the payment-account connection presented in the Owner dashboard. Follow the secure onboarding steps and return to EstateSync after completion. The dashboard must show the connection as ready or verified before property creation is enabled.

Starting payment onboarding without finishing it may leave the connection incomplete. Resume from the Owner dashboard rather than creating another owner account. If the payment provider requests corrections, complete them through the secure provider flow. Never provide bank credentials, card security codes, passwords, or one-time verification codes to the EstateSync assistant.

# What the Owner dashboard contains

The Owner dashboard organizes overview information, properties, rental applications, leases, complaints, site visits, and earnings. Each tab represents owner-side records only. For example, tenant applications submitted by the account appear in the tenant dashboard, while applications received for owned properties appear in the owner dashboard.

# Multiple properties

An owner may create more than one property. Every property follows its own draft and approval lifecycle. Approval of one property does not approve another, and documents, applications, leases, visits, and complaints remain associated with their specific property. An active lease on one property does not prevent the owner from listing another property.

# Common onboarding problems

If Become an Owner is unavailable, check KYC approval and confirm that the signed-in account is the verified account. If Add Property is unavailable after the upgrade, check the payment-account connection status. If the payment connection was completed but EstateSync still shows it incomplete, return through the expected completion path, refresh the dashboard, and wait briefly for the updated status before contacting support.

# Safe support boundaries

The assistant can explain the owner-upgrade and payment-connection flow, but it cannot verify bank ownership, change an owner type, access payout credentials, or bypass KYC. Use only the secure forms provided by the application. Support should never ask for passwords, full bank credentials, payment-card security codes, or identity-document images through ordinary chat.
