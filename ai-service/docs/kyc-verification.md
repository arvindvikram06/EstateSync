# Purpose and prerequisite

KYC is the identity-verification process used before sensitive rental activity. A user can browse properties before approval, but an approved KYC is required to submit rental applications and to complete the path to becoming a property owner. KYC is associated with the signed-in account and should be completed using the account holder’s own accurate information.

# Starting and saving a draft

Open the KYC or Verifications area from the dashboard and start a new verification when no current submission exists. Enter the requested personal information exactly as it appears on the supporting documents. A draft can be saved and continued later. Leaving a draft does not submit it for review, and a reviewer will not see it until submission is completed.

# Required documents

The KYC flow accepts the identity and address document types displayed in the upload form, including the required Aadhaar, PAN, and address-proof positions used by the current application. Upload each file into the correct slot. Images or documents should be readable, complete, correctly oriented, and free from glare or cropped edges. Do not upload passwords, payment-card details, unrelated documents, or files belonging to another person.

If a document is replaced before submission, confirm that the new file appears in the intended slot. A successful upload alone does not mean KYC is submitted. The application must contain the required information and document coverage before the Submit action becomes available.

# Submitting for review

Review the entered information and uploaded files before submitting. Submission changes the verification from Draft to a pending review state. While it is pending, the user should normally wait for a decision rather than creating another submission. The current status is visible in the dashboard, and a notification is sent when the review outcome changes.

# Approval

Approved means identity verification succeeded. The account displays the verified status, and KYC-gated actions such as applying for a property become available. Approval does not automatically create an owner profile, submit a rental application, or approve a property. Those remain separate workflows.

# Rejection and resubmission

Rejected means the reviewer could not approve the submitted information. The rejection reason should identify what needs attention, such as an unclear image, missing coverage, mismatched information, or an unsupported file. Open the existing verification, correct the stated problem, replace affected documents where necessary, and resubmit. A rejection is not a permanent account failure; corrected submissions can be reviewed again.

Do not change unrelated fields merely to make them different from the rejected submission. Corrections should match legitimate documents. If the stated reason is unclear or the correct information cannot be entered, contact support before submitting repeated incorrect attempts.

# Pending or delayed review

Pending means a reviewer has not completed a decision. The platform does not promise an exact completion time in the assistant documentation. Check the current status and notifications rather than repeatedly uploading the same files. If the item remains pending unusually long, contact support using the verification reference visible in the application, without emailing full document images unless an authorized secure process specifically requests them.

# Duplicate and consistency checks

Identity details intended to be unique cannot be reused across unrelated accounts. If the system reports that identity information is already associated with another account, sign in to the original account or contact support. Do not create additional accounts to work around the check. Names, identifiers, and document ownership must remain consistent with the person being verified.

# Privacy and safe handling

KYC files are private verification documents and are not shown on public property pages or shared with ordinary tenants and owners. They are used only for the required verification process. Users should review KYC status inside EstateSync rather than posting documents in chat. The assistant should never request complete Aadhaar numbers, PAN numbers, document images, passwords, or private sign-in links.

# Common reasons an action is blocked

Submit remains unavailable when required information or document coverage is incomplete. Apply remains unavailable while KYC is Draft, Pending, or Rejected. Become an Owner remains unavailable until the necessary identity approval is complete. If the KYC page appears empty after approval, use the dashboard’s Verifications or KYC-status view, which is designed to show the current state rather than reopening a completed wizard.
